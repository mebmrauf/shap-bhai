# Rebuild decisions

The user selected Snake vs Snake as the main competitive mode. Competition uses equal speed, mirrored starts, simultaneous collision resolution, and first-to-three rounds. Optional solo scoring/replays are kept out of 1v1 rules.

The menu uses two top-level choices and progressive native selects. A single primary action starts the selected mode. Buttons that do nothing in a state are hidden. Results explain the cause of death; the scoreboard distinguishes apples from round wins. Sound, pause, leave, and view controls remain beside the active arena.

Visual direction: warm paper, forest green, lime player 1, amber player 2, red apples, cyan ghost. Player numbers, names, and outline shape supplement color. No decorative emoji. The raised board keeps screen-aligned directions; flat view uses the same controls. Reduced motion disables interpolation.

Assets are local. The interface uses native font stacks plus a bundled Bengali font. Sound uses original Bengali scripts, generated speech clips, original oscillator effects, and an optional six-beat loop. Music and voice can be disabled independently.

The UI/UX skill's arcade guidance informed clear contrast, keyboard operation, responsive spacing, and visible focus. Its pixel-font and flashy-effect suggestions were not adopted because they conflict with the requested simpler interface. The 21st CLI was unavailable; no 21st components or hosted generation were used.
